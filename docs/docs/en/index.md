# Studio API Documentation

Welcome to the Studio API documentation! This document provides a complete API usage guide to help you quickly integrate Studio API into your applications.

## What is Studio API?

Studio API is a RESTful API and WebSocket API service for managing Studio devices and status. It provides the following main features:

- **Device Management**: Register, query, and update device information
- **Status Management**: Real-time status updates and queries
- **Error Signal Handling**: Send and process device error signals
- **Real-time Communication**: Bidirectional real-time communication via WebSocket

## Main Features

### HTTP API

- Device registration and management
- Status queries and updates
- Error signal log queries

### WebSocket API

- Real-time device status updates
- Real-time error signal notifications
- Device status change monitoring
