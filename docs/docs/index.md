# Studio API 文檔

歡迎使用 Studio API 文檔！本文件提供完整的 API 使用指南，幫助您快速整合 Studio API 到您的應用程式中。

## 什麼是 Studio API？

Studio API 是一個用於管理 Studio 設備和狀態的 RESTful API 和 WebSocket API 服務。它提供了以下主要功能：

- **設備管理**：註冊、查詢和更新設備資訊
- **狀態管理**：即時更新和查詢設備狀態
- **錯誤信號處理**：發送和處理設備錯誤信號
- **即時通訊**：透過 WebSocket 進行雙向即時通訊

## 主要功能

### HTTP API

- 設備註冊和管理
- 狀態查詢和更新
- 錯誤信號日誌查詢

### WebSocket API

- 即時設備狀態更新
- 錯誤信號即時通知
- 設備狀態變更監聽
